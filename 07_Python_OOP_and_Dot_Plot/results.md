# 1. Object-Oriented Programming

## Objective

To implement object-oriented Python classes for representing DNA and protein sequences. The classes were designed to organize biological information, store sequence-related metadata, and model the relationship between DNA, mRNA, and protein molecules.

## Method

Two Python classes were implemented:

- **DNA**
- **Protein**

Each class stores biological information including:

- Sequence name
- Accession number
- Official gene symbol
- Biological sequence
- Coding relationships

The implementation was tested using the human **TPI1** gene and its corresponding protein sequences obtained from NCBI RefSeq.

## Results

The Python program successfully created DNA and Protein objects for the human **TPI1** gene. The DNA object stored the genomic DNA sequence together with its accession number, official gene symbol, and the mRNA transcript encoded by the gene. The Protein object stored the translated amino acid sequence and identified all transcript variants that encode the corresponding protein isoforms.

## Interpretation

The object-oriented implementation successfully organized biological sequence information into reusable Python objects. Instead of storing biological data in separate variables, each DNA or Protein object groups all relevant properties and relationships into a single structure. This approach improves code organization, readability, and scalability, making it easier to manage biological sequence data in future bioinformatics analyses.
