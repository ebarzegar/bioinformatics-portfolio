A hands-on portfolio of **nine bioinformatics projects** integrating biological knowledge with computational analysis, from sequence and protein analysis to structural bioinformatics, NGS variant calling, phylogenetics, and gene-expression analysis.

### 🔬 Areas Covered

- Sequence and protein analysis
- Python programming for bioinformatics
- Multiple sequence alignment and comparative genomics
- Protein structure analysis and molecular docking
- Primer design and qPCR/RT-PCR analysis
- NGS quality control and read alignment
- Variant calling and functional annotation
- Phylogenetic analysis
- miRNA differential-expression analysis
