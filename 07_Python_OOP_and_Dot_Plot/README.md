# Project 7 – Object-Oriented Programming and Dot Plot Visualization

## Overview

Programming plays an essential role in modern bioinformatics, enabling researchers to organize biological data and develop custom analytical tools. In this project, I implemented two fundamental programming concepts in Python: object-oriented programming (OOP) for representing biological sequences and a custom dot plot algorithm for visualizing sequence similarity.

Rather than relying solely on existing bioinformatics software, I developed Python classes to model DNA and protein sequences and implemented a dot plot algorithm to compare amino acid sequences between different organisms.

---

## Learning Objectives
- Apply object-oriented programming concepts to biological data.
- Design reusable Python classes for DNA and protein sequences.
- Store biological information using object properties.
- Implement methods for displaying biological information.
- Validate DNA sequences programmatically.
- Represent relationships between genes, mRNA transcripts, and proteins.
- Build a dot plot algorithm from scratch.
- Visualize sequence similarity using Matplotlib.
- Interpret sequence conservation through graphical comparison.

---

## Project Structure

### Part 1 — Object-Oriented Programming

Python classes were created to represent DNA and protein molecules. Each class stores biological information such as sequence name, accession number, official gene symbol, sequence, and coding relationships.

---

### Part 2 — Dot Plot Visualization

A custom dot plot algorithm was implemented to compare protein sequences. The algorithm generates a similarity matrix and visualizes conserved amino acids using Matplotlib.
